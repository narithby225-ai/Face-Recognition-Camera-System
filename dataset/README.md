# Dataset Folder

ថតនេះសម្រាប់រក្សាទុករូបភាពមុខរបស់មនុស្សម្នាក់ៗ។

## រចនាសម្ព័ន្ធឯកសារ (File Structure)

```
dataset/
├── 001_Narith.jpg       # ID 1 - Narith
├── 002_Dara.jpg         # ID 2 - Dara
├── 003_Sokha.jpg        # ID 3 - Sokha
└── ...
```

## ទម្រង់ឈ្មោះឯកសារ (Naming Format)

```
[ID]_[Name].jpg
```

ឧទាហរណ៍ (Examples):
- `001_Narith.jpg`
- `002_Dara.jpg`
- `003_Sokha.jpg`

## ការប្រើប្រាស់ (Usage)

រូបភាពទាំងនេះនឹងត្រូវបានរក្សាទុកដោយស្វ័យប្រវត្តិនៅពេលចុះឈ្មោះ (Registration)។

---

# Dataset Folder (English)

This folder stores face images of each person.

## File Structure

```
dataset/
├── 001_Narith.jpg       # ID 1 - Narith
├── 002_Dara.jpg         # ID 2 - Dara
├── 003_Sokha.jpg        # ID 3 - Sokha
└── ...
```

## Naming Format

```
[ID]_[Name].jpg
```

Examples:
- `001_Narith.jpg`
- `002_Dara.jpg`
- `003_Sokha.jpg`

## Usage

Images are automatically saved here during registration.
